# Images for the FORGE site

Drop files here with **exactly these names**. Any slot without a file stays hidden, so the site never shows a broken image.
Preview every slot (with dashed placeholders + file names) by opening the site with `?slots`, e.g. `index.html?slots`.

| File | Where it shows | Suggested size | What works well |
|---|---|---|---|
| `studio.png` | Beside "The belief" text (tilted frame, parallax) | 1200 × 1500 (4:5 portrait) | Team at work, whiteboard session, studio desk |
| `cta-1.png`, `cta-2.png`, `cta-3.png` | Polaroids floating around "Let's build what's next" | 800 × 1000 (4:5) each | Product screens, sketches, team moments |
| `who-a.png` … `who-e.png` | Desktop only: follows the cursor over each "Who can apply" row (A–E) | 800 × 600 (4:3) | A = idea person, B = first-time founder, C = early startup team, D = founder with notes/research, E = existing business |
| `og.png` | Link preview on WhatsApp / LinkedIn / X | 1200 × 630 | Brand card: FORGE + "Your idea. Our build." |

Tips: keep each file under ~300 KB (compress at squoosh.app). `.png` names are expected; if you prefer `.jpg`/`.webp`, rename the `src` in `index.html` too.
